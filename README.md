# 🧠 Exercícios de Lógica de Programação com Visualg

## 📖 Sobre o projeto

Este repositório reúne exercícios de **lógica de programação** desenvolvidos utilizando **Visualg**, durante o curso do Instituto PROA.

Os exercícios têm como objetivo fortalecer o raciocínio lógico e a base de programação, abordando desde conceitos fundamentais até estruturas mais elaboradas.

---

## 🚀 Tecnologias utilizadas

* Visualg (Portugol)

---

## 💡 Conteúdos abordados

* Variáveis e tipos de dados
* Operadores aritméticos e lógicos
* Estruturas condicionais (`se`, `senao`)
* Estruturas de repetição (`para`, `enquanto`)
* Entrada e saída de dados
* Algoritmos básicos

---

## 📦 Como executar

1. Baixe e instale o Visualg
2. Abra o programa
3. Carregue qualquer arquivo `.alg`
4. Execute o algoritmo dentro do ambiente

---

## 🎯 Objetivo

O objetivo deste repositório é desenvolver uma base sólida em **lógica de programação**, essencial para o aprendizado de qualquer linguagem de programação.

---

## 📌 Observações finais

Este repositório faz parte dos meus estudos em programação e será atualizado conforme avanço no curso e na resolução de novos exercícios.
